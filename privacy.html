隱私權政策

生效日期 2026 年 11 月 5 日

本政策適用於「廣告羅盤」網站及相關本機分析工具。此專案僅供個人研究與學習，無商業營利行為。

網站瀏覽

網頁以靜態 HTML 提供，未加入分析追蹤程式、廣告追蹤像素、表單或第三方 JavaScript。網站由 GitHub Pages 託管，GitHub 會依其政策處理提供網站所需的技術資料，例如訪客 IP 位址。請參閱GitHub 隱私權聲明。

Google 資料存取與用途

市場研究使用關鍵字規劃工具提供的市場指標及其他可取得的公開資料。若個人研究需要查閱 Google Ads 帳戶資料，僅在取得 Google OAuth 授權後，依授權範圍讀取研究所需的資料，用於個人分析與筆記。

儲存與保護

OAuth 憑證保留在帳戶持有人的電腦，應由作業系統權限保護。查詢結果可能儲存在本機檔案，或由使用者選擇保留在對話及雲端文件中。公開網站只提供介紹文字。

AI 分析與分享

我們可使用 Google Gemini、ChatGPT 或 Codex 協助整理公開資料及分析重點。若需要將 Google API 資料或衍生摘要交由第三方處理，須先確認適用的 Google 政策允許該用途，並在分享前說明接收服務、資料範圍及用途，取得相關帳戶持有人同意。登入憑證和 API 金鑰不得提供給這些服務。

保留、刪除與撤銷

帳戶持有人可自行刪除本機憑證與查詢檔案。對話或雲端副本需分別在相應服務中刪除。可從 Google 帳戶的第三方連線管理撤銷授權，停止未來存取。撤銷授權後，既有副本仍需另行刪除。

使用限制與政策更新

Google 使用者資料僅用於使用者要求的工具功能，遵守 Google API Services User Data Policy，包括 Limited Use 規範。工具用途或資料處理方式變更時，應先更新本政策及相關授權說明。

資料管理

如需詢問資料處理或要求刪除，請透過頁尾的支援信箱聯絡我們。
