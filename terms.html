服務條款

適用範圍

本網站介紹「廣告羅盤」，供帳戶持有人在自己的電腦上研究 Google Ads 資料與分析廣告成效。本網站提供公開的工具說明與政策頁面。

帳戶與授權

使用工具前，帳戶持有人須透過 Google 授權，並遵守 Google Ads 與 Google Ads API 的適用條款。請只存取你有權使用的帳戶與資料。你可隨時在 Google 帳戶設定撤銷授權。

分析結果與投放決策

分析結果供研究參考，可能受資料完整性、帳戶權限及 API 可用性影響。使用者應核對結果，並自行決定廣告設定、預算與投放方式。

隱私與聯絡方式

關於資料存取、使用與刪除，請參閱隱私權政策。如有問題，請寄信至 adcompass.support@gmail.com。
