關於廣告羅盤

廣告羅盤是個人自用的廣告分析工具，目的在於協助帳戶持有人研究自己的廣告投放需求，並理解廣告成效。

使用流程

  1. 帳戶持有人透過 Google OAuth 授權本機程式。
  2. 程式以 Google Ads API 讀取權限允許的資料。
  3. 使用者核對報表，並可選擇使用 ChatGPT 協助分析。

功能與權限

已建立的本機 SDK 可進行帳戶查詢。關鍵字研究待 Basic 存取權核准後啟用。受眾洞察、觸及預估與創作者洞察若需使用，仍須另外符合 Google 的開通條件。

網站與工具的關係

本網站以靜態 HTML 提供介紹。網站顯示的名稱為「廣告羅盤」，目前 Google Cloud 專案的 OAuth 應用程式名稱為「Google Ads SDK」。兩者對應同一個個人自用工具。

維護與資料問題

本工具由帳戶持有人自行管理。資料存取、保留與刪除方式請見隱私權政策。
