投放方向

廣告羅盤由帳戶持有人使用 Google Ads Python SDK，在自己的電腦上查詢獲授權的廣告資料，再整理成容易理解的分析。

關鍵字研究

規劃透過 Google Ads API 查詢關鍵字提案與歷史搜尋量，協助比較搜尋需求。此功能目前等待 Basic 存取權核准，尚未取得搜尋量結果。

廣告成效整理

使用已授權且可存取的帳戶資料，檢視活動狀態及可用的曝光、觀看與費用指標。實際可查內容依帳戶狀態及 Google API 權限而定。

AI 輔助理解

帳戶持有人可選擇將查詢摘要交給 ChatGPT，協助比較數據及撰寫分析。分析結論由使用者核對，廣告設定與預算由使用者決定。

這個網站提供工具介紹與資料處理說明。工具的查詢作業在帳戶持有人的電腦執行。
